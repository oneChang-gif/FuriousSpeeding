# 부위 공격과 지뢰

## 구현

- 좌클릭 서버 공격은 ApplyPointDamage를 사용한다. 맞은 차량의 WheelSetups BoneName과 HitInfo.BoneName을 비교한다.
- 바퀴를 맞으면 코인 보유량과 무관하게 BonusMaxSpeed에서 WheelSpeedPenalty(기본 10)를 뺀다. 기존 코인 강탈 처리는 유지한다.
- PlayerState 서버 Tick에서 음수 BonusMaxSpeed를 초당 5씩 회복하고 0에서 멈춘다. 양수 보너스는 회복 처리로 변경하지 않는다. 예: 0 → -10 → 0, 기존 보너스 20이면 피격 후 10.
- 이 변경은 BonusMaxSpeed 수치를 처리한다. 현재 프로젝트에는 이 수치를 실제 차량 최고 속도에 적용하는 C++ 속도 제한 코드가 없다.
- F키는 Boolean PlaceMineAction의 Started 이벤트로 CTSPlaceMine 서버 RPC를 호출한다. C++에서 F 매핑을 추가하므로 기존 IMC에 중복 등록하지 않는다.
- 서버는 차량 뒤 400cm 위치의 지면을 찾고 지뢰를 생성한다. SpawnActorDeferred의 Owner와 Instigator는 설치한 차량이다. 기본 설치 간격은 1초이다.
- 지뢰 오버랩은 서버만 판정한다. 피해 차량의 소유 클라이언트로 Reliable Client RPC를 보내고, 가속 차단 상태도 OwnerOnly로 복제한다. 입력 콜백과 Tick에서 가속 입력을 0으로 유지한다.
- 2초 후 서버가 차단을 해제한다. 중복 피격 시 마지막 피격 시점부터 2초이다. 브레이크와 조향은 유지하며 차량의 관성 속도를 강제로 0으로 만들지 않는다.
- 폭발 상태를 복제하여 파티클과 사운드를 한 번만 재생한다. 메쉬와 충돌은 즉시 꺼지고, 상태 전파를 위해 숨겨진 액터를 1초 유지한 뒤 파괴한다.
- 설치한 차량도 지뢰를 밟으면 영향을 받는다.

## BP 연결

1. CXMine을 부모로 BP_CXMine을 만든다.
2. MineMesh에 메쉬, ExplosionParticle에 Cascade 파티클, ExplosionSound에 사운드를 지정한다. 구체 반경 기본값은 100cm이며 메쉬 충돌은 끈다.
3. 사용하는 차량 BP의 Mine Class를 BP_CXMine으로 지정한다. 미지정 시 기본 C++ 지뢰는 스폰되지만 메쉬와 효과가 없다.
4. 차량 Physics Asset에서 바퀴 Bone에 쿼리 가능한 충돌 바디가 있는지 확인한다. Vehicle 메쉬는 Visibility 트레이스를 Block해야 한다. 바퀴 바디가 없으면 Hit Bone이 차체로 판정되므로 바퀴 피격 효과가 발동하지 않는다.
5. 콘텐츠 브라우저의 Input Action 애셋이 필요하면 /Game/VehicleTemplate/Input/Actions/IA_PlaceMine을 Boolean으로 만들고 차량 BP의 Place Mine Action에 지정한다. F키 매핑은 C++이 처리한다. 애셋 미지정이어도 C++ 기본 InputAction으로 작동한다.

IA_PlaceMine.uasset 자동 생성 명령을 시도했으나 생성 파일을 확인하지 못했다. create_mine_input.py는 에디터의 Python Editor Script Plugin을 켠 뒤 Execute Python Script로 실행할 수 있는 애셋 생성 스크립트이며, 실행 시 기존 애셋은 덮어쓰지 않는다. 생성 후 차량 BP에 할당한다.

## 직접 확인할 항목

빌드와 플레이 테스트는 수행하지 않았다.

1. 에디터를 닫고 프로젝트를 직접 빌드한다. 새 반영 속성과 클래스가 있으므로 Live Coding만으로 적용하지 않는다.
2. 호스트와 클라이언트 양쪽에서 공격한다. 차체는 속도 보너스를 변경하지 않고 바퀴는 기본 10 감소시켜야 한다.
3. 피해 차량 코인이 0일 때도 바퀴 패널티가 적용되는지 확인한다.
4. BonusMaxSpeed가 -10이면 약 2초 후 0이 되고, 회복만으로 양수가 되지 않는지 확인한다. 양수 버프를 먹는 것은 회복과 별도이다.
5. 호스트와 클라이언트 각각 F키를 눌러 뒤쪽 지뢰 스폰과 Owner가 설치 차량인지 확인한다.
6. 다른 차량이 가속 키를 누른 채 지뢰를 밟았을 때 피해 차량만 가속 입력이 즉시 0이 되는지 확인한다. 이동 관성은 남는다.
7. 2초 후 누르고 있던 가속 입력이 다시 적용되는지, 연속 피격 시 마지막 피격으로부터 2초인지 확인한다.
8. 서버와 모든 클라이언트에서 폭발 파티클과 사운드가 한 번만 재생되고 지뢰가 사라지는지 확인한다.
